# Contributing

Issues and focused pull requests are welcome.

1. Use Node.js 22 or newer.
2. Run `npm ci`.
3. Add tests for behavior changes.
4. Run `npm run release:check` before opening a pull request.

Do not commit API keys, `.env` files, customer data, or replay traces containing
real input. By contributing, you agree that your contribution is licensed
under the repository's MIT license.
